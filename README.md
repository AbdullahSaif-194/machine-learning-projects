# 🤖 Machine Learning Projects

A collection of **Supervised** and **Unsupervised** Machine Learning projects built with scikit-learn, pandas, and numpy. Each project covers a real-world use case with full EDA, preprocessing, model training and evaluation.

## 📂 Projects

### 📈 Supervised Learning

| Project | Algorithm | Dataset | Task |
|---------|-----------|---------|------|
| **Linear Regressor** | Linear Regression | Insurance dataset | Predict insurance charges |
| **Logistic Regressor** | Logistic Regression | Heart disease + Iris | Binary & multi-class classification |
| **Credit Wise** (Mini Project) | Multiple classifiers | Loan approval data | Predict loan approval |
| **NpyqGe Project** | Supervised ML | Novagen dataset | Classification task |

### 🔵 Unsupervised Learning

| Project | Algorithm | Dataset | Task |
|---------|-----------|---------|------|
| **K-Means Clustering** | K-Means | - | Customer segmentation |
| **DBSCAN** | DBSCAN | - | Density-based clustering |
| **Agglomerative Hierarchy** | Hierarchical Clustering | - | Dendrogram analysis |
| **Smart Cart** (Mini Project) | K-Means | Customer data | Retail customer segmentation |

## 🛠️ Tech Stack

- **Python 3.12**
- **scikit-learn** — ML algorithms
- **pandas / numpy** — Data manipulation
- **matplotlib / seaborn** — Visualization
- **Jupyter Notebook** — Development environment

## ⚙️ Setup

```bash
# 1. Clone the repo
git clone https://github.com/AbdullahSaif-194/machine-learning-projects.git
cd machine-learning-projects

# 2. Install dependencies
pip install scikit-learn pandas numpy matplotlib seaborn jupyter

# 3. Launch Jupyter
jupyter notebook
```

> **Note:** Datasets are not included in this repo. Each notebook contains instructions on how to obtain the dataset.
